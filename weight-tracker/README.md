# 🏃 昕露的减肥计划 - 使用说明

## 快速开始

### 一键启动（推荐）
双击 `start.bat`，自动启动服务器并打开浏览器。

### 手动打开
直接双击 `index.html` 文件，即可在浏览器中打开（AI 识图功能不可用）。

### 命令行启动
```bash
cd weight-tracker
node proxy-server.js
```

启动后，在网页的"设置"中配置：
- API 地址: `http://localhost:3000/api/recognize`
- API Key: 你的豆包 API Key

## 功能说明

### 📊 仪表盘
- 查看当前体重、目标进度、今日计划
- 体重趋势图可视化

### ⚖️ 体重记录
- **手动记录**: 点击"+ 记录体重"按钮
- **AI 识图**: 点击"📷 AI 识图"按钮，上传小米运动健康截图自动识别
- 查看体重、BMI、体脂率变化趋势

### 🍽️ 饮食记录
- 记录早/中/晚/加餐
- 自动计算每日热量摄入
- 与热量目标对比

### 🏋️ 运动计划
- 每日晨间训练计划（核心 + 盆底肌 + 深蹲）
- 每周运动安排
- 运动记录打卡

### 📊 报告中心
- 当日报告
- 完成情况报告
- 周报

### ⚙️ 设置
- 修改个人信息
- 调整热量目标
- 配置 AI 识图 API
- **数据导出/导入**（JSON 备份）

## 数据说明

所有数据存储在浏览器的 localStorage 中：
- ✅ 关闭浏览器后数据不会丢失
- ✅ 支持 JSON 文件导出备份
- ⚠️ 清除浏览器缓存会丢失数据
- 💡 建议定期使用"导出数据"功能备份
